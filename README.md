# Landing Page – Estúdio de Tatuagem

Landing page de um estúdio de tatuagem, feita com **HTML e CSS puros**. Apresenta o trabalho, mostra um portfólio e leva o visitante a um formulário de orçamento.

> **Projeto de estudo**, sem fins comerciais e sem vínculo com o profissional ou o estúdio citados. Textos, imagens e contatos são apenas demonstrativos.

🔗 **Ver online:** https://felipecsantos-dev.github.io/SamuelSanguinete/

![Prévia da página](imagens/preview.png)

## Seções

Hero · Sobre · Destaque do mês · Portfólio · Como funciona · Dúvidas frequentes · Agendamento · Rodapé

## Tecnologias e recursos

- HTML5 semântico
- CSS3 com Grid, Flexbox e variáveis (`:root`)
- Layout responsivo com `@media`
- FAQ em acordeão com `<details>`, sem JavaScript
- Google Fonts (Cormorant Garamond e Inter)
- SEO: meta tags, Open Graph e JSON-LD
- Git, GitHub e GitHub Pages
